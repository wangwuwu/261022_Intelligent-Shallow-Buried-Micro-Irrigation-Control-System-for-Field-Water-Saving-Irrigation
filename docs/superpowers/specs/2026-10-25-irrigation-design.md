# 田间智能浅埋微灌节水灌溉管控系统：第一版功能范围

日期：2026-10-25

> 2026-10-26 实施补充：本文件保留原范围依据。当前开发顺序、截图映射、前端交互、数据契约和验收口径以 [详细开发 spec](2026-10-26-irrigation-development-spec.md) 为准。本轮仅交付 Vue 前端，完成后等待用户确认才开发后端；真实设备接入不在本轮执行。

## 1. 已确认的建设范围

- 建设真实设备接入版，连接现场已安装的灌溉设备。
- 第一版包含九个业务模块，以及账号权限、参数配置和操作日志。
- 主业务流程为：田块与管网建档 → 设备接入与监测 → 制定策略和计划 → 分区轮灌执行 → 异常处理 → 用水分析。
- 本文用于确定功能范围。通信协议、设备控制时序、数据点位、部署方式和具体页面交互需在设备资料核实后细化。

## 2. 使用角色

| 角色 | 职责 |
| --- | --- |
| 系统管理员 | 管理账号权限、设备接入配置、基础参数与日志 |
| 灌溉管理人员 | 维护田块、种植、分区、策略和计划，分析用水情况 |
| 灌溉操作人员 | 查看现场状态，执行授权范围内的灌溉操作，处理运行异常 |
| 巡检维护人员 | 记录巡检、设备故障、管带维修及处理结果 |

角色可由同一人员兼任，操作权限按账号配置。

## 3. 第一版功能模块

### 3.1 灌溉总览

- 汇总田块数量、灌溉面积、当前种植季用水和当日用水。
- 展示正在执行和即将执行的灌溉任务、分区运行状态。
- 展示墒情概况、设备在线情况及未处理告警。
- 从汇总数据进入对应田块、设备、任务或告警详情。
- 无数据、数据过期和设备离线应明确标识，不能按正常值展示。

### 3.2 田块与种植管理

- 维护田块名称、位置、面积、土壤类型和负责人。
- 维护种植季、作物、种植日期和生育阶段。
- 关联灌溉分区、监测点和灌溉记录。
- 保留历史种植季与灌溉记录，种植信息变更不覆盖历史记录。

### 3.3 管网与分区管理

- 维护水源、泵站、主管、支管、阀门及滴灌带档案和关联关系。
- 登记滴灌带埋深、间距、规格及设计流量等现场参数，不预设统一农艺值。
- 建立田块、灌溉分区、控制阀门和计量点的对应关系。
- 配置共享泵站、允许同时运行的分区等调度约束。
- 提供管网关联查询；地图展示形式在页面设计阶段确定。

### 3.4 设备与监测管理

- 维护设备厂家、型号、编号、安装位置、所属分区、通信方式及采集点位。
- 按现场设备能力接入土壤含水率、土壤温度、流量、压力及泵阀状态。
- 降雨等气象数据根据现场气象设备或外部数据接口情况接入。
- 展示实时数据、历史趋势、数据时间、通信状态和数据有效性。
- 保存测量单位、传感器安装深度、量程和校准记录。
- 通信接入方式依据厂家协议或平台接口确定，不默认所有设备可直接控制。

### 3.5 灌溉策略管理

- 按田块、作物和生育阶段维护墒情阈值、单次目标水量、执行时段等规则。
- 支持定时、定量和墒情触发策略；各模式启用条件依据实际传感与控制能力确定。
- 支持生成灌溉建议，由管理人员确认并转为灌溉计划。
- 自动执行作为受控模式，在设备反馈、联动与现场保护条件核实后启用。
- 策略变更保留记录；已生成任务保存当时使用的策略参数。

### 3.6 计划与轮灌调度

- 创建计划，配置目标田块、分区、执行时间、轮灌顺序和终止条件。
- 检查共享泵站、同时运行分区和已安排任务的资源冲突。
- 提供待执行、执行中、暂停、已完成、已取消和失败等任务状态。
- 支持暂停、恢复和取消；对应现场操作结果必须通过设备反馈确认。
- 分别记录计划水量、实际计量水量、起止时间和异常中断原因。
- 缺少分区独立计量时，明确水量的测量或分摊口径。

### 3.7 现场运行控制

- 按设备开放的控制接口执行水泵启停、阀门开关等操作。
- 配置符合现场工艺的泵阀联动顺序和运行条件，具体顺序由现场资料确认。
- 区分指令已发送、设备已应答和状态已确认，避免将通信成功当作动作完成。
- 处理指令失败、反馈超时、状态不一致和重复操作；重试策略依据协议及指令性质制定。
- 展示手动、远程和自动模式，明确模式切换条件和控制权。
- 断网后的任务执行、现场保护和恢复行为依现场控制器能力确定。
- 提供有权限控制的停止入口，操作结果仍以现场反馈为准。

### 3.8 告警与维护管理

- 对设备离线、数据过期、压力异常、流量异常、控制失败和任务超时生成告警。
- 告警支持确认、处理、恢复与关闭，并记录时间和责任人员。
- 记录巡检、过滤器维护、滴灌带破损修复、疑似堵塞排查及维修结果。
- 流量和压力异常用于提示排查方向，具体漏水或堵塞原因由现场确认。
- 告警关联设备、分区和受影响任务；通知渠道在实施阶段确定。

### 3.9 用水与节水分析

- 按田块、分区、作物、种植季和时间范围统计用水。
- 计算亩均用水量、计划与实际用水偏差、任务完成情况。
- 区分实测、估算和分摊数据，记录采用的计算口径。
- 配置可比较的基准后展示节水量和节水率，显示基准来源及适用范围。
- 基准缺失或为零时不计算节水率；缺少产量数据时不计算单位产量用水指标。
- 支持按筛选条件导出灌溉记录和统计数据。

## 4. 配套管理功能

- 账号与角色权限：分别控制查看、计划编辑、设备操作、参数配置等权限。
- 基础参数：管理数据单位、阈值、数据过期时间、超时等参数。
- 操作日志：记录操作人员、对象、时间、参数、指令结果与实际反馈。

## 5. 硬件能力与功能依赖

| 功能 | 需要核实的现场条件 |
| --- | --- |
| 远程泵阀控制 | 控制柜或控制器开放控制接口，并提供动作反馈或状态采集 |
| 分区定量灌溉 | 具备可归属到分区的计量能力，或明确采用估算口径 |
| 墒情触发灌溉 | 具备可代表目标分区的有效墒情数据，并配置适用阈值 |
| 泵阀联动 | 明确水力条件、现场启停顺序、状态反馈和保护逻辑 |
| 断网运行 | 现场控制器支持本地任务、控制逻辑及相应运行记录 |
| 自动异常停机 | 现场设备具备相应检测和保护能力，平台与现场控制职责清晰 |

上述功能属于规划范围，其实现方式和可启用状态须经设备资料与联调核实。

## 6. 开发前需要核实的资料

1. 设备厂家、型号、数量及安装位置清单。
2. 通信协议、网关接口或厂家平台 API 文档及接入权限。
3. 设备数据点表：地址或字段、读写权限、单位、量程、上报频率与状态含义。
4. 水源、泵站、管网、阀门、计量点与田块的现场对应关系。
5. 控制柜操作模式、联动条件、保护逻辑及断网行为说明。

取得资料后，为相关功能标注“直接支持”“需要改造”或“后续扩展”，再确定设备接入设计与开发计划。

## 7. 后续扩展

水肥一体化、天气预测驱动的灌溉优化、用电成本分析和更复杂的作物需水模型可在后续版本讨论，不列入当前第一版必交范围。

## 8. 验收方向

- 能从田块追溯到灌溉分区、阀门、泵站和对应监测点。
- 能完成计划创建、资源检查、分区执行、设备反馈和实际用水归档的完整流程。
- 能区分控制指令成功、动作确认、失败及反馈缺失。
- 能识别离线和过期数据，并保留异常处理和维护记录。
- 能追溯统计水量的来源与节水比较基准。
- 具体设备型号、试验条件、响应时限和精度要求在设备资料确认后形成联调验收清单。
